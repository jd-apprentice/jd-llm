# Examples

This directory holds examples generated with the **`qwen3.6:35b-a3b`** model
to showcase its capabilities. Each project is intended as a starting point,
showing how to apply the model's output to a concrete task — whether a command
line tool or a web application.

## Models used

Every example in this directory was created with a single model:

- **`qwen3.6:35b-a3b`** — a 35B-parameter open-weight model from the Qwen
  family. Its strong reasoning, code generation, and instruction-following make
  it ideal for producing React components, Tailwind layouts, and complete
  project scaffolds — all locally, with no API calls required.
