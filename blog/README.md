## Publishing

- There is no static site generator in this repo. Each post is a standalone Markdown file, so it can be published on GitHub, a blog platform or a future site without changes.
- Relative links to repository files use `../` from this folder. Links that must survive a copy to another platform use absolute GitHub URLs.
- New posts go in this table and in the Blog section of the top-level [README](../README.md).
